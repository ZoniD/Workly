# Workly Frontend Redesign

The frontend was rebuilt around a cohesive dark 3D design language while preserving the existing REST API.

## Public site
- immersive hero with subtle Three.js geometry
- live category count and approved profile count
- dynamic category filters and text search
- responsive professional cards
- live published-news area
- login/register modal
- authenticated professional application modal

## Admin
- control-surface layout
- live dashboard metrics
- professional filtering/status controls
- create/deactivate/restore workflows
- news editor and publish/draft/archive actions

## Professional portal
- identity/status overview
- rating/category/profile metadata
- live availability switch
- editable public profile

## Accessibility/performance
- semantic controls and labels
- keyboard-visible focus states
- responsive layouts
- `prefers-reduced-motion` support
- 3D is decorative and non-blocking
